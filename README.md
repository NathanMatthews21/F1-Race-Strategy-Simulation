# F1 Race Strategy Simulator

A Python-based Formula 1 race strategy simulation engine.

## Current Version

V0.1

## Objective

Build a simulation engine capable of modelling:

- Race pace
- Tyre degradation
- Fuel load
- Driver performance
- Car performance
- Pit stops
- Weather
- Safety Cars
- Traffic
- Strategy
- Monte Carlo race simulation

## V0.1

The first version models:

- Circuit
- Driver
- Car
- Tyre compound
- Tyre degradation
- Fuel load
- Lap-to-lap randomness
- Complete race simulation
